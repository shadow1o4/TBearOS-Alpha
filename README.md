# TBearOS
This is a custom project to put Linux and windows combined without use of wine or any of that, This is for combining essentially windows 10 / 11 kernel and compatibility support Into a Linux OS for things like anti-cheat working in Linux for things like Cod, Fortnite, And many others!! It will also allow for support for Microsoft things In the settings for instance toggling OneDrive on and off in setting and like win 10 / 11 OneDrive would appear as its own folder when enabled and work like it would in windows but you can choose what you do with it! This whole project so far has 1 contributor and hoping people can help make this into a full blown reality!!
